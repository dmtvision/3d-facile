# Composants tiers

3D-Facile inclut les composants suivants, hébergés dans `vendor/` (aucun n'est chargé depuis Internet).
Toutes ces licences autorisent un usage commercial ; elles imposent de conserver les mentions de copyright et le texte de licence fournis.

| Composant | Version | Usage dans 3D-Facile | Licence | Texte |
|---|---|---|---|---|
| [three.js](https://threejs.org) | r128 | Affichage 3D | MIT | [`vendor/three/LICENSE`](vendor/three/LICENSE) |
| [manifold-3d](https://github.com/elalish/manifold) | 3.0.1 | Fusion des formes, trous, coupe à la table (export étanche) | Apache 2.0 | [`vendor/manifold/LICENSE`](vendor/manifold/LICENSE) |
| [Fredoka](https://github.com/hafontia/Fredoka-One) (police) | Google Fonts | Titres et boutons | SIL Open Font License 1.1 | [`vendor/fonts/OFL-Fredoka.txt`](vendor/fonts/OFL-Fredoka.txt) |
| [Nunito](https://github.com/googlefonts/nunito) (police) | Google Fonts | Textes | SIL Open Font License 1.1 | [`vendor/fonts/OFL-Nunito.txt`](vendor/fonts/OFL-Nunito.txt) |

Notes :
- La licence Apache 2.0 de manifold-3d n'impose pas de fichier NOTICE supplémentaire pour cette version (aucun fichier NOTICE n'est distribué avec le paquet).
- Les polices sont des sous-ensembles « latin » et « latin-ext » au format WOFF2, non modifiés, issus de Google Fonts.
